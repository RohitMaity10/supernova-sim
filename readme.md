# 💥 Supernova // Cosmic Nucleosynthesis Lab

An interactive astrophysics simulation modeling the core collapse of a massive star, relativistic shockwave expansion, and R-process cosmic nucleosynthesis of heavy elements, written in Vanilla JavaScript and HTML5 Canvas.

## 🌐 Live Demo
Trigger core collapse: [https://rohitmaity10.github.io/supernova-sim/](https://rohitmaity10.github.io/supernova-sim/)

## Technical Highlights
- **Core-Collapse Mechanics:** Simulates the collapse of an iron core when electron degeneracy pressure fails against gravity.
- **R-Process Nucleosynthesis:** Tracks real-time element synthesis percentages for Iron (Fe), Gold (Au), Platinum (Pt), and Uranium (U) as shockwave compression varies.
- **High-Energy Remnants:** Produces either a rapidly spinning pulsar with rotating relativistic beams or a stellar-mass black hole depending on the progenitor star's initial solar mass ($M_\odot$).
- **Web Audio Sound Synthesis:** Generates a real-time low-frequency fusion rumble and an explosive acoustic shockwave blast during detonation.
